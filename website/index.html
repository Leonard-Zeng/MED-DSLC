MED-DSLC: Multi-Expert-Domain Classification via Domain Supervision and Logit Calibration

Zheng Zeng*Deepak Sridhar*Nuno Vasconcelos

ECCV 2026

arXiv Code Weights

Abstract

Vision-language models such as CLIP classify images by comparing image and text features in a shared embedding space. This requires logits to be globally comparable across candidate classes. Adapting CLIP to specialized domains with LoRA improves in-domain recognition, but independently trained experts can produce incompatible logit scales. When classes from multiple domains compete under a single softmax, this miscalibration creates cross-domain interference.

We propose MED-DSLC, a mixture-of-experts approach that combines domain-supervised routing with domain-wise logit calibration. The CLIP backbone and expert LoRAs remain frozen. A gating network learns to combine domain expertise, while a learned temperature for each domain aligns logit magnitudes without changing within-domain class rankings. Across nine fine-grained recognition benchmarks, MED-DSLC improves cross-domain mean accuracy over LoRA-Mean by 15.39 percentage points on the base split and 6.83 points on the all split, without requiring domain labels at inference.

Method

Domain supervision. Domain labels are derived from training class labels and used to supervise the gating network. The model learns input-dependent combinations of independently trained LoRA experts.

Logit calibration. A positive temperature is learned for each domain. Scaling the domain’s logits before the joint softmax preserves its within-domain ranking while making scores more comparable across domains.

Results

We evaluate classification over a unified label space spanning Caltech101, EuroSAT, Stanford Cars, Food101, Oxford Pets, Oxford Flowers, DTD, UCF101, and FGVC Aircraft. The benchmark contains 783 classes after filtering overlapping categories.
